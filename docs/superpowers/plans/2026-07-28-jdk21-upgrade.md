# JDK 8 → JDK 21 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the project from JDK 8 to JDK 21, remove the `Jdk8Helpers` compatibility shim, and update documentation.

**Architecture:** Bump compiler target to 21, replace 4 `Jdk8Helpers` methods with their built-in JDK equivalents (`Files.writeString`, `Files.readString`, `InputStream.transferTo`, `OutputStream.nullOutputStream`), delete the shim class, and update docs.

**Tech Stack:** JDK 21, Maven, no new dependencies.

## Global Constraints

- Source and target must be `21` (not `1.8`) in pom.xml
- `Jdk8Helpers` class must be deleted entirely after all references are removed
- Modern JDK features (streams, lambdas, records, var, text blocks) are available but not required for this upgrade
- All existing tests must pass after the upgrade
- `build-exe.bat` already uses JDK 21 — no change needed
